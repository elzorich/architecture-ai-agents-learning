# Architecture Decision Records

Architecture Decision Records (ADRs) explain why an important technical choice
was made. Add them only when architectural work begins; Phase 1 should focus on
the problem rather than solutions.

## Naming

Use sequential filenames:

```text
0001-use-python-fastapi.md
0002-use-postgresql.md
```

## Status values

- Proposed
- Accepted
- Superseded
- Rejected

Start from [`0000-adr-template.md`](0000-adr-template.md).

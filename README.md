# Architecture, Stacks & AI Agents

This repository documents a mentorship learning project about approaching a
software problem systematically: from requirements and architecture to
implementation, AI features, and agents.

The current learning vehicle is a small booking application. The domain and
scope are intentionally provisional and may change after mentor discussions.

## Learning principles

- Build in thin, working slices.
- Start with deterministic business logic.
- Add AI only where it creates clear value.
- Record important architectural decisions.
- Keep new ideas in a backlog instead of expanding the current slice.
